# Lesson 07 - Vue.js IV

## Slots

Slot, um lugar onde conseguimos reservar espaço para adicionar um html dentro de um componente.

Usa-se o tag slot para fazer essa reserva do lugar no componente.

### slots padrão

O conteúdo adicionado no corpo do componente será apresentado no lugar onde é colocado o slot. Logo pode-se ter apenas um.

### slots nomeados

Usa-se a tag template com classes para condicionar a renderização e ter mais de um espaço reservado.
