# Lesson 02 - JS Essencial I

## Contexto

- JavaScript é uma linguagem interpretada, o código é executado sem uma compilação prévia.
- Ela roda tanto do lado do cliente quando do lado do servidor.
- É padronizada pela ECMA International.
- Pode-se usar JS para programar absolutamente qualquer coisa.
- Para rodar JS precisa-se de um servidor rodando.

## Variáveis

Nos primórdios, as declararíriamos com let, hoje em dia usamos let ou const.

A grande diferença entre elas está no escopo
var - escopo de função
let e const - escopo de bloco
